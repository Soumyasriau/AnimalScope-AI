AnimalScope AI: Animal Image Classification using MobileNetV2

Project Overview

This project implements a deep learning model to classify animal images into 3 categories: Cat, Dog and Bird.

The model was developed using Python, TensorFlow and Keras, with MobileNetV2 (pretrained on ImageNet) as the feature extractor. It uses transfer learning, image augmentation and fine-tuning.

Final Test Accuracy: 100% (on a 16-image test set)

An interactive web application was also developed using FastAPI and React, allowing users to upload images and receive predictions with confidence scores.

Live Demo: https://soumya-animalscope.vercel.app/

Model Architecture

The model uses MobileNetV2 as a pretrained feature extractor with a small classification head on top.

Main components:

  • Data Augmentation: RandomFlip, RandomRotation and RandomZoom to improve robustness.
  • MobileNetV2: Pretrained on ImageNet, extracts image features.
  • GlobalAveragePooling2D: Reduces feature maps to a 1280-dimensional vector.
  • Dropout (0.3): Helps reduce overfitting.
  • Dense: Classification layer with 3 outputs.
  • Softmax: Produces prediction probabilities for the 3 classes.

Project Workflow

  1. Load the dataset from Roboflow.
  2. Resize images to 224 × 224.
  3. Apply data augmentation.
  4. Build the MobileNetV2 transfer learning model.
  5. Compile the model (Adam optimizer, Sparse Categorical Crossentropy loss).
  6. Train the classification head with the backbone frozen (20 epochs).
  7. Fine-tune the last 30 MobileNetV2 layers.
  8. Monitor training and validation performance using Early Stopping and ReduceLROnPlateau.
  9. Save the trained model (animal_classifier.keras).
  10. Evaluate the model on unseen test images.
  11. Generate a classification report and confusion matrix.
  12. Build the FastAPI backend and React frontend for image predictions.

How to Run the Project

1. Clone the repository

git clone https://github.com/Soumyasriau/AnimalScope-AI.git
cd AnimalScope-AI

2. Start the backend

cd backend
python -m venv .venv

Activate the virtual environment:

# Windows
.venv\Scripts\activate

# Linux / macOS
source .venv/bin/activate

Install dependencies and run the API:

pip install -r requirements.txt
uvicorn app:app --reload

3. Start the frontend (in a new terminal)

cd frontend
npm install

Create a .env file inside the frontend folder:

VITE_API_URL=http://127.0.0.1:8000

Start the development server:

npm run dev
